### 2. Функциональность

#### Быстрые суммы
```javascript
// При клике на быструю сумму:
1. Поле amount обновляется
2. Поле получает анимацию (scale 0.95 -> 1)
3. Кнопка "пульсирует" (scale 1 -> 0.95 -> 1)
4. Потенциальный выигрыш пересчитывается
```

#### Выбор методов оплаты
```javascript
// При клике на метод оплаты:
1. Метод получает класс .active
2. Показываются нужные поля ввода
3. Остальные поля скрываются
4. Скрытое поле payment_method обновляется
```

#### Выбор ставок
```javascript

1. Вариант получает класс .selected
2. Обновляется коэффициент
3. Пересчитывается потенциальный выигрыш
4. Обновляется скрытое поле bet_type
```

## Возможные проблемы и решения

### Проблема: Анимации не работают
**Решение:**
1. Проверить что файл buttons.css подключен
2. Очистить кеш браузера (Ctrl+Shift+Del)
3. Перезагрузить страницу (Ctrl+F5)

### Проблема: Быстрые суммы не работают
**Решение:**
1. Проверить что buttons.js подключен
2. Открыть DevTools (F12) -> Console
3. Проверить нет ли ошибок (красные сообщения)
4. Проверить что элементы имеют data-amount

### Проблема: Кнопки обрезаны на мобильном
**Решение:**
1. Проверить метатег viewport в base.html
2. Проверить что используются responsive классы
3. Проверить CSS media queries

### Проблема: Валидация не работает
**Решение:**
1. Проверить что форма имеет required атрибуты
2. Проверить DevTools -> Console на ошибки
3. Проверить что JavaScript не заблокирован

## Запуск сервера для тестирования

```bash
# Активировать виртуальное окружение
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt

# Миграции
python manage.py migrate

# Запустить сервер
python manage.py runserver

# Открыть http://localhost:8000
```
