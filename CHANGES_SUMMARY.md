## Как использовать новые функции

### В HTML шаблонах:

```html
<!-- Кнопка с ripple эффектом -->
<button class="btn btn-gold btn-ripple">Действие</button>

<!-- Быстрые суммы -->
<button class="quick-amount" data-amount="1000">1000 ₽</button>

<!-- Методы оплаты -->
<div class="payment-method" data-method="card">Карта</div>

<!-- Кнопка с tooltip -->
<button class="btn btn-tooltip" data-tooltip="Подсказка">Кнопка</button>

<!-- Кнопка с loading -->
<button class="btn btn-loading">Загрузка...</button>
```

### В JavaScript:

```javascript
// Форматирование сумм
formatAmount(1000); // "1 000 ₽"

// Обновление баланса с анимацией
updateBalanceAnimated(5000);

// Показать уведомление на кнопке
showButtonNotification(button, 'Успешно!', 2000);

// Обновить потенциальный выигрыш
updatePotentialWin();
```
