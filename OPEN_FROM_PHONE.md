Как открыть ваш локальный проект на телефоне (пошагово, для чайников)

Кратко: самый простой и безопасный путь — использовать ngrok. Ниже — полная инструкция.

Выбор в приветственном окне ngrok:

- **Select a role:** любой (неважно для базовой работы).
- **What are you interested in using ngrok for?** выберите **"Sharing local apps without deploying"**.
- Если вы также планируете принимать и тестировать Stripe вебхуки, дополнительно выберите **"Testing Webhooks on local"**.

1) Подготовка (один раз)
- Убедитесь, что у вас установлен Python и вы можете запускать `python` в PowerShell.
- Установите ngrok: скачайте с https://ngrok.com/ и распакуйте; добавьте путь к `ngrok.exe` в системную переменную PATH.
  - (Опционально) Зарегистрируйтесь на ngrok, получите auth token и выполните `ngrok authtoken <ваш_token>`.

2) Готовность проекта
- В проекте уже включён режим разработки: `DEBUG = True`, и временно `ALLOWED_HOSTS = ['*']` в файле `applications/settings.py`.
  - Внимание: это только для локального тестирования. Не делайте так в продакшене.

3) Автоматический запуск (рекомендуется для Windows)
- В корне проекта есть скрипт `start_for_phone.ps1`. Он делает две вещи: запускает `python manage.py runserver 0.0.0.0:8000` и, если в PATH есть `ngrok`, запускает `ngrok http 8000`.
- Запуск (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -File .\start_for_phone.ps1
```

- Через несколько секунд в консоли появится публичный URL от ngrok (например, `https://abcd-1234.ngrok.io`). Откройте этот URL на телефоне — ваш сайт будет доступен.

4) Ручной запуск (если не хотите скрипт)
- В одном окне PowerShell запустите:

```powershell
python manage.py runserver 0.0.0.0:8000
```

- В другом окне (после установки ngrok):

```powershell
ngrok http 8000
```

- Скопируйте https-URL ngrok и вставьте его в браузер телефона.

5) Остановка
- Остановить Django: в окне, где он запущен, нажмите Ctrl+C.
- Остановить ngrok: в окне ngrok нажмите Ctrl+C.

6) Частые проблемы и их решения
- "Не открывается с телефона": проверьте, что телефон подключён к интернету (не обязательно в той же сети), убедитесь, что вы используете HTTPS-URL от ngrok.
- "ngrok не найден": добавьте `ngrok.exe` в PATH или запускайте полный путь до `ngrok.exe`.
- "Страница показывает ошибки" — возможно, у вас в проекте есть зависимости. Убедитесь, что установлены пакеты из `requirements.txt`.

7) Безопасность и что сделать после теста
- После тестирования обязательно верните `DEBUG = False` и корректно настройте `ALLOWED_HOSTS` в `applications/settings.py`.
- Не оставляйте `ALLOWED_HOSTS = ['*']` и `DEBUG = True` в публичном или продуктивном окружении.

Если хотите, могу:
- Запустить скрипт прямо сейчас (нужен доступ к терминалу) и показать URL ngrok, или
- Подготовить аналогичный скрипт для macOS/Linux.
